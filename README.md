# 公会探求团中文文本补丁

全年龄向汉化文本，改掉几处不良暗示的补丁包。

适用游戏：Welcome to the Guild Explorers（欢迎来到公会探求团）。

## 安装

1. 关闭游戏。
2. 在 Steam 中右键游戏，选择「管理」→「浏览本地文件」。
3. 将游戏目录中原有的 `locate.data` 复制到其他文件夹，留作备份。
4. 把本补丁包中的 `locate.data` 复制到游戏目录，覆盖同名文件。
5. 正常启动游戏即可。

## 还原

关闭游戏后，用第 3 步备份的原文件覆盖游戏目录中的 `locate.data`。

## 内容

- 优化中文对话和说明，使表达更自然。
- 改掉指定卡牌对话中的露骨暗示，以及结尾小女孩对调查大叔的恋爱暗示。
- 保留人名、队名、职业、检索关键词和游戏文本控制标记。

本补丁只替换文本，不包含游戏程序、美术、音频或存档。名称中的「全年龄向」描述的是文本修改方向，不代表游戏整体内容已接受年龄评级或完整审查。

文本结构已通过检查，尚未完成全部游戏页面的显示验证。游戏更新或 Steam 验证文件完整性后，可能需要重新安装补丁。
